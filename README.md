# Análisis de Clientes Bancarios

Caso de análisis de clientes bancarios realizado en Python y Power BI.

## Prueba realizada:

- Análisis exploratorio de los datos.
- Identificación de patrones relacionados con la aceptación de campañas.
- Análisis de variables como edad, saldo, ocupación, educación, estado civil y duración de llamadas.
- Modelos de clasificación con Logistic Regression y Random Forest.
- Evaluación mediante Accuracy, Precision, Recall, F1 y ROC-AUC.
- Segmentación de clientes según probabilidad de aceptación.
- Preparación de datos para visualización en Power BI.

## Archivos

- `input-eda.ipynb` — análisis exploratorio y modelado.
- `cleaning.ipynb` — limpieza y preparación de datos.
- `clientes_powerbi.csv` — datos utilizados para el dashboard.
